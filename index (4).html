How it works

From the rack to your screen in under a second

Each ESP32 node publishes a small JSON message to an MQTT broker. The dashboard subscribes to the same topic over a secure WebSocket, so a new reading appears on screen as soon as it is sent.

  1. SENSE

    Rack sensor

    A DHT22 on the rack inlet measures temperature and humidity every 5 s.

  2. PUBLISH

    ESP32 node

    Classifies the reading, drives the fan and buzzer, and publishes JSON over Wi-Fi.

  3. ROUTE

    MQTT broker

    Receives every reading on hossam7192/datacenter/# and forwards it to subscribers.

  4. SHOW

    Dashboard

    Subscribes over WebSocket, updates charts, floor map and alerts in real time.

    Setup guide

    Get live data on the dashboard

    The ESP32, MQTT Explorer and this page all talk to the same MQTT broker. The ESP32 and MQTT Explorer use normal MQTT (port 1883). A web page can only use MQTT over a WebSocket, so the dashboard uses the broker's WebSocket port.

    Message format

    TopicPayload (plain text)
    hossam7192/datacenter/temperature25.50  (°C)
    hossam7192/datacenter/humidity45.20  (%RH)
    hossam7192/datacenter/fan/statusON or OFF

    The dashboard subscribes to hossam7192/datacenter/# and merges the values into one reading. It also accepts JSON such as {"rack":"R-A1","temperature":23.4,"humidity":45} on hossam7192/datacenter/R-A1, so more racks can be added later.

    Broker addresses

    Used byHostPort
    ESP32, MQTT Explorerbroker.emqx.io1883
    Dashboard (browser)wss://broker.emqx.io:8084/mqtt8084

    The public broker is shared by everyone, so anyone can read these messages. Keep the topic unique and send no secrets. For a private setup, use a free EMQX Cloud or HiveMQ Cloud broker and enter its username and password.

    1. Connect MQTT Explorer to the broker

      • Install MQTT Explorer from mqtt-explorer.com and open it.
      • Click + to add a connection. Name: CoolWatch, Protocol: mqtt://, Host: broker.emqx.io, Port: 1883, Encryption off, no username or password.
      • Open Advanced, delete the default # subscription and add hossam7192/datacenter/#. Click Back, then Connect.

    2. Connect this dashboard to the same broker

      Open Dashboard → Live MQTT. Keep the broker URL wss://broker.emqx.io:8084/mqtt and topic hossam7192/datacenter/#, then press Connect. The pill at the top turns green.

    3. Send a test message from MQTT Explorer

      • In the Publish panel on the right, set Topic to hossam7192/datacenter/temperature and choose raw (plain text).
      • Type 25.50 and press Publish. The value appears in the message log and on the floor map.
      • Publish 33 to see a critical alert, and ON to hossam7192/datacenter/fan/status to switch the fan card. Everyone watching the topic sees test values too, so tell your team first.

    4. Flash the ESP32

      Upload the CoolWatch firmware with your Wi-Fi details in secrets.h. It publishes every 5 s to the same topic, and you can watch the messages arrive in MQTT Explorer and on the dashboard at the same time.

    5. Host the page online with GitHub Pages

      • Create a public repository, for example coolwatch-dashboard, and upload this page as index.html in the root.
      • Go to Settings → Pages. Under Build and deployment choose Deploy from a branch, branch main, folder / (root), and save.
      • After a minute the page is live at https://<your-username>.github.io/coolwatch-dashboard/.
      • Because the page uses HTTPS, the broker URL must start with wss://. A plain ws:// broker is blocked by the browser.
