# IoT Data Center Cooling Monitoring System

## Project Overview

The **IoT Data Center Cooling Monitoring System** is a web-based monitoring solution designed to help monitor environmental conditions inside data centers and improve cooling management.

Data centers contain servers and networking equipment that generate heat during operation. If temperatures become too high, equipment performance can decrease, hardware can become damaged, and system reliability can be affected.

Our project focuses on using Internet of Things (IoT) technology to monitor important environmental parameters, visualize collected data, and identify potential cooling problems through an interactive dashboard.

## Project Objectives

The main objectives of this project are to:

- Monitor temperature and humidity conditions inside a data center.
- Track cooling system performance.
- Visualize environmental information through an interactive dashboard.
- Identify abnormal temperature conditions.
- Generate alerts when environmental values exceed defined thresholds.
- Improve awareness of potential overheating risks.
- Support efficient data center monitoring and cooling management.

## Key Features

### 1. Temperature Monitoring
Monitor temperature levels to identify overheating conditions and maintain a suitable environment for data center equipment.

### 2. Humidity Monitoring
Track humidity levels to help maintain appropriate environmental conditions for servers and other electronic equipment.

### 3. Cooling System Monitoring
Display cooling system status and provide an overview of cooling performance.

### 4. Interactive Dashboard
Present important monitoring information using visual indicators, charts, statistics, and dashboard components.

### 5. Alerts and Notifications
Highlight abnormal environmental conditions and potential cooling problems to help users respond quickly.

### 6. Server Rack Heatmap
Provide a visual representation of temperature conditions across server racks to help identify areas with higher heat levels.

## Technologies and Tools

The project focuses on combining the following technologies:

- **Internet of Things (IoT):** Environmental monitoring through connected devices and sensors.
- **ESP32:** Microcontroller platform for sensor integration.
- **MQTT:** Communication protocol for transferring IoT sensor data.
- **Web Technologies:** Dashboard development and data visualization.
- **JavaScript:** Interactive dashboard functionality.
- **HTML and CSS:** Website structure and styling.

*The technologies listed describe the project architecture and intended integration; actual implementation may depend on the current development stage.*

## How the System Works

The system follows a simple monitoring workflow:

1. IoT sensors collect environmental data, such as temperature and humidity.
2. An ESP32-based device can transmit the collected information.
3. MQTT can be used to communicate sensor data to the monitoring application.
4. The web dashboard displays the received information.
5. The dashboard helps users identify abnormal conditions through charts, indicators, and alerts.
6. Users can monitor cooling conditions and identify potential overheating risks.
